# 习题工坊 · 使用说明

面向：小学生家长、小学老师、托管 / 教培机构。

习题工坊是一个装在浏览器里的「出卷机」：选年级和题型，点打印，就能得到 A4 练习卷。所有题目由本地算法生成，答案自动计算，不联网也能用。

---

## 一、第一次使用

1. 解压下载的压缩包（或直接打开在线地址）。
2. 双击 `index.html`，浏览器会打开应用。推荐 Chrome 或 Edge。
3. 上方四个标签页对应四类练习：**口算练习 / 竖式计算 / 汉字字帖 / 单词默写**。
4. 左侧「练习设置」里改参数，右侧 A4 预览会实时更新。
5. 点右上角 **打印 / 导出 PDF** → 打印目标选「另存为 PDF」。

> 小提示：每次修改参数后，页面地址会自动记录当前设置。把这个地址收藏或发给同事，打开就是同一份卷子。

## 二、四类练习怎么用

### 1. 口算练习

- **年级**：决定数字范围。一年级为 20 以内加减；二年级为 100 以内加减 + 表内乘除；三年级到六年级逐步扩大并支持混合运算。
- **运算类型**：点击 `+ - × ÷` 切换。一年级只有加减。
- **混合运算**（4 年级起）：勾选后自动出「先乘除后加减 / 带括号」的题，如 `(221 - 53) × 6`。
- **有余数除法**（4 年级起）：答案形式为 `7……3`。
- **每列题数 / 列数**：决定一页多少题。40 题约 10 分钟。
- **多页 / 打包**：设成 20、30 页，就是一本练习册。
- **答案页**：勾选后答案单独成页，可单独打印或家长留存。
- **随机种子**：同样的种子 → 同样的卷子；点「换一批」换一套。用两个不同种子就能出 A/B 卷。

### 2. 竖式计算

- 适合练「数位对齐、进位退位、乘法竖式」。
- 题目下方留了完整书写空间；每页默认 3 列 × 5 题。
- 除法竖式请使用教材专用格式，本工具不自动排版除法竖式。

### 3. 汉字字帖

- **练习内容**：从下拉框选古诗 / 常用字，或直接在「自定义文字」里粘贴课文、生字表。只保留汉字，标点和数字会被忽略。
- **每页行数 / 每行格数**：控制字帖密度。
- **描红格数**：每字前几格显示浅红描红字，其余为空格临写；设为 0 就是「看拼音默写」。
- **格子类型**：田字格 / 米字格 / 空白格。
- **拼音**：自动标注（多音字取常用读音）。也可关掉，让孩子自己写拼音。
- 重复的字去重后只出现一次，适合逐字练习。

### 4. 单词默写

- 内置小学 3–6 年级共 200 个基础词，按主题分组；也可在「自定义词表」里每行输入一个 `英文 中文`（空格或逗号分隔）。
- **默写方向**：看中文写英文（四线三格）或看英文写中文（横线）。
- **每页词数**：6–13 个。
- 勾选「答案页」后，答案页会列出英文和中文对照。

## 三、打印设置（重要）

| 项目 | 建议 |
| --- | --- |
| 纸张 | A4 纵向 |
| 缩放 | 100%（不要选「适应页面大小」，否则格子会缩小） |
| 边距 | 默认 |
| 背景图形 | 建议勾选（田字格红线、四线三格会完整打印） |
| 页眉页脚 | 关闭 |

黑白打印机也完全可用：田字格会呈现为浅灰线条，不影响书写。

如果打印后发现内容被截断，请检查是否把缩放设成了「适应页面」或纸张选成了 Letter。

## 四、批量出 PDF（老师 / 机构）

方法一：在网页里把「多页」设成需要的页数，点打印 → 另存为 PDF。

方法二：用 Chrome 命令行批量生成（详见 README「方式三」）。`auto=1` 参数会隐藏界面只输出页面，非常适合脚本化。

常见批量场景：

- 一个年级一个文件：`?mode=oral&grade=1&pages=30&ans=1&auto=1`
- 每日一练 5 页、按天分文件：把 `seed` 依次改成不同值
- 字帖整本：`?mode=hanzi&preset=jingyesi&auto=1`
- 单词默写 10 页：`?mode=words&list=grade4&per=12&pages=10&ans=1&auto=1`

## 五、常见问题

**Q1：为什么题目不能按教材单元出？**
本工具不依赖教材内容，只按年级生成通用计算 / 书写练习。若需与某个教材版本对齐，可以自行修改 `assets/generate.js` 里的数字范围，或提 Issue 说明需求。

**Q2：刷新后设置丢了？**
设置记录在地址栏参数里；只要地址没变，刷新后设置仍在。清空地址后的 `?` 部分即可恢复默认。

**Q3：拼音有错？**
拼音来自本地词库（pinyin-pro），多音字可能取到不常用读音。遇到具体字可以反馈，或在 `data/presets.js` 里避开。

**Q4：能给孩子在平板上做吗？**
可以预览和设置，但写字练习建议打印。打印建议在电脑上完成。

**Q5：可以商用吗？**
代码和生成的题目为 MIT 开源协议，可用于课堂教学与机构内部使用；请勿宣称「官方配套」或提分效果，也不要转售本工具本身（可以转售自己用工具生成并排版好的 PDF，前提是不虚假宣传）。

**Q6：数据会被上传吗？**
不会。项目没有任何后端与统计脚本，全部在浏览器本地运行，断网可用。
