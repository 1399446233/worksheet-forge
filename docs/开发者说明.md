# 开发者说明

本文档面向二次开发：目录职责、状态模型、渲染接口、打印约束与扩展方式。

## 1. 设计目标

- **零构建、零依赖**：所有脚本用经典 `<script>` 加载，`file://` 直接打开也能用，方便部署到任意静态托管。
- **确定性**：题目由种子随机数生成，同一参数永远得到同一份卷子。
- **打印优先**：页面按 A4 物理尺寸排版（mm 单位），浏览器打印即成品，不依赖前端 PDF 库。
- **可打包**：`auto=1` 参数隐藏所有 UI，仅输出页面序列，便于无头浏览器批量导出 PDF。

## 2. 目录与职责

```text
index.html             应用骨架：顶栏、控件容器、预览容器、脚本加载顺序
assets/style.css       屏幕样式 + @media print + @page A4 规则
assets/generate.js     纯算法层：随机数、加减乘除/混合运算/竖式生成、拼音封装
assets/render.js       版面层：把 state 渲染成 .sheet 页面 HTML 字符串数组
assets/app.js          控制层：状态、URL 参数、控件、事件、预览刷新
data/words.js          内置英语词表（window.WF_WORDS）
data/presets.js        字帖预设（window.WF_PRESETS）
assets/pinyin-pro.umd.js  第三方拼音库（MIT），通过 window.pinyinPro 调用
```

加载顺序固定：`pinyin-pro → presets → words → generate → render → app`。

## 3. 状态模型

`app.js` 内的 `DEFAULTS` 定义了全部状态字段，运行时挂在闭包里，通过 `WF.state()` 读取快照：

| 字段 | 类型 | 说明 |
| --- | --- | --- |
| `mode` | string | `oral` / `vertical` / `hanzi` / `words` |
| `auto` | bool | 自动导出模式（隐藏 UI） |
| `grade` | number | 1–6 |
| `ops` | string[] | 运算子集，如 `['+','-','×']` |
| `mixed` / `remainder` | bool | 混合运算 / 有余数除法 |
| `cols` / `rows` | number | 列数、每列题数 |
| `pages` | number | 生成页数（练习页） |
| `answers` | bool | 是否附加答案页 |
| `seed` | number | 随机种子 |
| `title` | string | 自定义标题（空则自动） |
| `showHeader` | bool | 是否显示姓名/班级/日期栏 |
| `hanziPreset` / `hanziText` | string | 字帖预设 id / 自定义内容 |
| `hanziRows` / `cells` / `trace` | number | 每页行数 / 每行格数 / 描红格数 |
| `showPinyin` / `grid` / `dedupe` | bool/string/bool | 拼音 / 格子类型 / 去重 |
| `wordsList` / `wordsDir` / `wordsPerPage` | string/string/number | 词表 / 方向 / 每页词数 |
| `customWords` | string | 自定义词表（每行 `en 中文`） |

URL 参数与字段的映射见 `readURL()` / `writeURL()`，参数名在 README「URL 参数」表中有完整说明。

## 4. 算法层 API（generate.js）

```js
WF.rng(seed)                       // mulberry32，返回 () => [0,1)
WF.ri(rng, a, b)                   // 闭区间随机整数
WF.genQuestions({grade, ops, count, mixed, remainder, seed})
    // → [{expr:'25 + 17', ans:'42', op:'+'}]
WF.genVertical({grade, ops, count, seed})
    // → [{a:383, b:277, op:'-', ans:'106'}]
WF.shuffle(arr, seed)
WF.pinyin(ch)                      // 单字拼音，库缺失时返回 ''
WF.parseWordTable(text)            // 'apple 苹果' × n → [['apple','苹果']]
```

约束：

- 加减法保证结果非负；一年级和 ≤ 20；除法保证整除（`remainder` 开启时答案形如 `7……3`）。
- 混合运算覆盖：`a×b±c`、`(a+b)×c`、`(a-b)×c`、`a÷b+c`、`a×b+c×d` 等模式，除法项保证整除。
- 同一页内表达式去重；`guard` 上限防止死循环。

## 5. 版面层 API（render.js）

```js
WF.buildPages(state) -> string[]   // 每项是一页 <article class="sheet"> 的 HTML
```

内部结构：

- `sheetHTML({title, subtitle, metaKind, body, pageNo, total, tip})`：统一页眉 / 页脚 / 页码。
- `buildOral / buildVertical / buildHanzi / buildWords`：各模块的实现。
- 答案页复用同一套 sheet 模板，页脚页码连续。

### 打印尺寸约定

- `@page { size: A4; margin: 12mm; }` → 可打印区域 186mm × 273mm。
- `.sheet` 屏幕与打印均按 `186mm × 271mm` 设计；打印时 `padding: 3mm`，`break-after: page`。
- 所有纵向内容的高度预算约 235mm。修改字号或行数时请重新核算，避免内容被 `overflow: hidden` 截断。
- 自适应间距：口算 `--gap`、竖式 `--vspace`、字帖格子尺寸、单词 `--wwrite` 都由渲染函数按行数计算，新增板块时建议沿用同样的思路。

## 6. 扩展新题型

以「应用题」为例：

1. **算法**：在 `generate.js` 增加 `WF.genWordProblems(opts)`，返回 `[{stem, ans}]`。
2. **渲染**：在 `render.js` 增加 `buildWordProblems(state)`，生成题目正文与作答横线；注册到 `WF.buildPages` 的 switch。
3. **控件**：在 `app.js` 增加 `controlsWordProblems()`，并在 `renderControls()` 中分发；在 `DEFAULTS` 中补默认字段，在 `readURL/writeURL` 中补参数。
4. **样式**：在 `style.css` 增加对应类，注意打印分页（`break-inside: avoid`）。

保持「算法与排版分离」：渲染函数只消费数据，不生成随机数。

## 7. 本地验证

```bash
# 直接打开（macOS/Linux 下也可用 python -m http.server 起静态服务）
start index.html

# 无头 Chrome 验证打印（Windows 示例）
"C:\Program Files\Google\Chrome\Application\chrome.exe" --headless=new --disable-gpu ^
  --no-pdf-header-footer --print-to-pdf="test.pdf" ^
  --virtual-time-budget=8000 ^
  "file:///D:/worksheet-forge/index.html?mode=oral&grade=3&pages=3&ans=1&auto=1"

# 用一段 Python 统计 PDF 页数（粗检分页是否正常）
python -c "import re;b=open('test.pdf','rb').read();print(len(re.findall(rb'/Type\s*/Page\b',b)))"
```

回归检查清单：

- 四个模块的预览页数与 `pages` / 内容长度匹配；
- 答案页紧跟练习页、页码连续、标题不重复；
- 单页与多页 PDF 均无空白页、无内容截断；
- 低年级（1 年级）不出现乘除、不出现负数；
- 字帖拼音、田字格、描红在黑白打印下可辨认。

## 8. 兼容性

- 目标浏览器：Chrome / Edge 90+、Firefox 90+、Safari 15+。
- 使用 `URLSearchParams`、`Element.closest`、CSS Grid 与 CSS 变量；IE 不支持。
- 打印依赖浏览器自带 PDF 导出（Chrome/Edge 的「另存为 PDF」最稳定）。
